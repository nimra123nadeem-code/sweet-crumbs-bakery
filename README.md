# Sweet Crumbs Bakery 🍞

A responsive bakery website designed and built with Webflow as a personal practice project.

## Live Website
[View Sweet Crumbs Bakery](https://nimras-stunning-site-be357d.webflow.io/untitled)

## Project Overview
Sweet Crumbs Bakery is a bakery website concept designed to showcase bakery products in a warm, welcoming, and user-friendly layout.

## Features
- Responsive layout for desktop and mobile
- Hero section with call-to-action buttons
- Featured bakery product cards
- Interactive hover effects and image zoom
- Why Choose Us section
- Customer testimonial section
- Navigation links and footer
- Basic accessibility checks

## Tools & Technologies
- Webflow
- HTML & CSS concepts
- Responsive Web Design
- Webflow Interactions
